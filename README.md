## 🛠️ Experiment Index

### 📂 Module 1: Linear Arrays & Memory Management
*   📄 `01_matrix_operations.c` — Matrix addition, subtraction, and algebraic multiplication.
*   📄 `02_array_manipulation.c` — Element insertion, deletion, and sequential traversal in 1D arrays.

### 📂 Module 2: Searching & Sorting Foundations
*   📄 `03_search_algorithms.c` — Implementation and performance analysis of Linear and Binary Search.
*   📄 `04_elementary_sorting.c` — Structural logic for Bubble Sort and Selection Sort.
*   📄 `05_insertion_sort.c` — Implementation of adaptive Insertion Sort.

### 📂 Module 3: Restrictive Data Structures (Stacks & Queues)
*   📄 `06_stack_adt.c` — Array-based implementation of Stack Abstract Data Type (Push, Pop, Peek).
*   📄 `07_infix_to_postfix.c` — Arithmetic expression parsing and evaluation using Stack logic.
*   📄 `08_queue_adt.c` — Operations on Linear Queues and Circular Queues.

### 📂 Module 4: Dynamic Memory & Linked Lists
*   📄 `09_singly_linked_list.c` — Creation, dynamic insertion, nodal deletion, and traversal of Singly Linked Lists.
